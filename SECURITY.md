# Security and privacy

Tally is a local-first, unsigned evaluation application. Public packages are distributed only through this repository's Releases. Download the full ZIP or Setup and compare SHA256SUMS.txt; do not disable OS protection to bypass a warning.

This repository is a binary/product site. It does not contain the private C# application source or development Git history. License restrictions are not a technical guarantee against reverse engineering.

## Reporting
For a security concern, report the affected version and a minimal, non-sensitive description through this repository's available reporting channel. Do not post exploit-ready personal records, credentials, private backups, real financial data or unredacted receipts in a public issue. If confidential reporting is not available, begin with a minimal issue requesting a private channel rather than disclosing sensitive details.

For ordinary bugs, use the issue template and synthetic/redacted examples. A source/development recovery ZIP is private and must never be attached to a public issue.

## Data and updates
No bank connection, built-in cloud synchronization or automatic update check is required. An explicit action to open an official download link uses your browser. Back up the complete profile after quitting Tally before updating. SQLite databases, sidecars, local attachments and preferences belong together; do not merge independently edited profiles.

Preview25 packages preserve the previously qualified application DLL. Installer compilation and portable extraction are verified. Fresh install/uninstall testing was not performed during this packaging run while a personal Tally instance was open. Testing on Windows 11 x64/125% is not universal certification across DPI, OS, GPU or accessibility configurations.
